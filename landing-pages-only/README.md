# Landing Pages Only

This folder is reserved exclusively for landing page files and assets.

## Allowed
- Landing page HTML, CSS, JS, and related assets
- Landing-page-specific content, sections, and components
- Media used directly by landing pages

## Not allowed
- Shared app logic unrelated to landing pages
- Backend services or APIs
- General-purpose components that belong elsewhere in the repo
- Unrelated experiments or scratch files

Please keep everything in this folder focused on landing-page work only.
