# espacios-me/w

Static Vercel-ready landing page for Espacios.

## Local development

```bash
npm install
npm run dev
```

Then open the local URL shown by `serve`.

## Deploy to Vercel

1. Import the `espacios-me/w` repository into Vercel.
2. Framework preset: **Other**.
3. Build command: leave empty.
4. Output directory: leave empty.
5. Deploy.

This project is a zero-build static site, so Vercel can serve `index.html` directly.
